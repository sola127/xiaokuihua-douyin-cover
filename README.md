# 小葵花抖音封面 Skill

根据中文文案、人物照片或视频截图，制作真人描边、大标题、贴纸拼贴风的视频封面。

## 适合哪些场景

商场活动、探店、口播、旅行、教育与穿搭。默认单张 3:4 竖版，可指定 9:16 或横版。

- 从文案提炼主标题、副标题和必要信息。
- 尽量保留人物、服饰与场景辨识度，按主题调整颜色与排版。
- 核对中文、数字、日期和优惠条件，交付封面图片及生成提示词。

## 运行条件

这是供 Codex 使用的工作流技能，不是独立生图程序。运行环境需要提供内置图片生成工具，以及可用的 `imagegen` 技能。仅下载本仓库不会获得生图服务、账号额度或工具权限；请以实际运行环境为准。

## 安装为 Codex Skill

在支持技能安装的 Codex 环境中，把下面这句话发给 Codex：

> 使用 skill-installer，从 https://github.com/sola127/xiaokuihua-douyin-cover 安装 skills/xiaokuihua-douyin-cover。

安装后重启 Codex，使新技能生效。安装技能本身不会安装上述生图依赖。

## 使用示例

上传自己的照片或视频截图，然后输入：

> 使用 $xiaokuihua-douyin-cover，根据这张照片做一张 3:4 探店封面。主标题：周末去哪逛；副标题：我的商场探店日记。保留我的脸、衣服和手势，采用奶油白与暖红配色。

活动封面请提供真实的日期、地点、优惠规则与最终文案。风格参考图请标明为参考，不会默认复制其中人物、品牌和文案。
